# Cadet Flight Manual

Welcome to the Shadow Arena testing phase! Follow these instructions to get your environment set up to play on the Midnight Preprod Network.

## 1. Install 1AM Wallet
You must use the **1AM Wallet Chrome Extension** to interact with the dApp.
- Download it from the Chrome Web Store.
- Create or import an account.

## 2. Switch to Preprod
The Midnight Preview Network is officially deprecated.
- Open the 1AM Wallet extension.
- Go to Settings > Network.
- Switch the active network to **Midnight Preprod**.

## 3. Get Testnet tDUST
You need tDUST to stake in matches.
- Go to the [Midnight Preprod Faucet](https://faucet.preprod.midnight.network/).
- Enter your `mn_addr_preprod1...` address.
- Request funds. They should arrive in ~30 seconds.

## 4. Play
1. Navigate to the Shadow Arena Lobby.
2. Click **Connect Wallet**.
3. Create a table (with a public or private wager).
4. Share the link with an opponent, or wait in the lobby!
